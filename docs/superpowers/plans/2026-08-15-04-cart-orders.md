# DADA Portal — Plan 03: Cart, Checkout & Staff Queue Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a restaurant build a cart from the catalog, check out through `create_order` (idempotent client_token), see their order history, and let staff confirm/cancel orders through the existing state-machine RPCs — full lifecycle verified end-to-end with a temporarily-priced test SKU.

**Architecture:** Server-first, zero client components (house style). Cart = httpOnly JSON cookie (`{productId: qty}`, capped) written only by server actions; prices are NEVER in the cookie (re-resolved from `products_priced` at render and by `create_order` at submit). Checkout calls the RPC on the caller's authenticated client; staff actions call `staff_confirm_order`/`staff_cancel_order` (they gate on `private.is_staff()` internally — belt) after `assertStaff` (suspenders).

**Existing RPC contracts (authoritative, live in cloud):**
- `create_order(p_lines jsonb, p_delivery_date date default null, p_note text default null, p_client_token uuid default null) → jsonb` — lines `[{product_id, qty}]`; errors: `NO_ACTIVE_COMPANY`, `COMPANY_NOT_LINKED`, `EMPTY_ORDER`, `TOO_MANY_LINES`, `BAD_DELIVERY_DATE` (Madrid today..+60), `BAD_QTY`, `PRODUCT_UNAVAILABLE:<uuid>`, `NO_PRICE:<codart>:tier N`; duplicate client_token returns the existing order.
- `staff_confirm_order(p_order_id uuid, p_staff_note text default null) → boolean` — false = wrong state (alertable, render a message, do not assume success).
- `staff_cancel_order(p_order_id uuid, p_reason text default null) → boolean`.

import { CART_COOKIE, CART_MAX_LINES, parseCart, serializeCart, setQty } from "./cart";

describe("cart codec", () => {
  it("round-trips", () => {
    const c = { "11111111-1111-4111-8111-111111111111": 2, "22222222-2222-4222-8222-222222222222": 0.5 };
    expect(parseCart(serializeCart(c))).toEqual(c);
  });

    expect(parseCart(undefined)).toEqual({});
    expect(parseCart("not json")).toEqual({});
    expect(parseCart("[1,2]")).toEqual({});
    expect(parseCart('{"x": "nan"}')).toEqual({});
    expect(parseCart('{"11111111-1111-4111-8111-111111111111": -2}')).toEqual({});
  });
  it("setQty adds, updates, and removes at qty<=0", () => {
    let c = setQty({}, "11111111-1111-4111-8111-111111111111", 3);
    c = setQty(c, "11111111-1111-4111-8111-111111111111", 5);
    expect(c["11111111-1111-4111-8111-111111111111"]).toBe(5);
    c = setQty(c, "11111111-1111-4111-8111-111111111111", 0);
    expect(c).toEqual({});
  });
  it("caps lines at CART_MAX_LINES", () => {
    let c: Record<string, number> = {};
    for (let i = 0; i < CART_MAX_LINES; i++) c = setQty(c, `00000000-0000-4000-8000-${String(i).padStart(12, "0")}`, 1);
    expect(() => setQty(c, "99999999-9999-4999-8999-999999999999", 1)).toThrow("CART_FULL");
    expect(setQty(c, `00000000-0000-4000-8000-${"0".repeat(12)}`, 2)).toBeTruthy(); // updating an existing line is fine
  });
  it("clamps precision to 3 decimals and rejects absurd qty", () => {
    const c = setQty({}, "11111111-1111-4111-8111-111111111111", 0.1234);
    expect(c["11111111-1111-4111-8111-111111111111"]).toBe(0.123);
    expect(() => setQty({}, "11111111-1111-4111-8111-111111111111", 100000)).toThrow("BAD_QTY");
  });
  it("exposes the cookie name", () => {
    expect(CART_COOKIE).toBe("dada_cart");
  });
});

- [ ] **Step 2: implement `src/lib/cart.ts`** (pure, no I/O):

```ts
/**
 * Cart = { productId: qty } in an httpOnly cookie. Quantities only — prices are
 * NEVER stored client-side (re-resolved from products_priced at render and by
 * create_order at submit). Cap keeps the cookie far under 4KB and under
 * create_order's TOO_MANY_LINES (200).
 */
export const CART_COOKIE = "dada_cart";
export const CART_MAX_LINES = 60;
const MAX_QTY = 9999;

export type Cart = Record<string, number>;

const UUID = /^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/i;

export function parseCart(raw: string | undefined): Cart {
  if (!raw) return {};
  let data: unknown;
  try {
    data = JSON.parse(raw);
  } catch {
    return {};
  }
  if (!data || typeof data !== "object" || Array.isArray(data)) return {};
  const cart: Cart = {};
  for (const [id, qty] of Object.entries(data)) {
    if (!UUID.test(id)) continue;
    const n = typeof qty === "number" ? qty : Number.NaN;
    if (!Number.isFinite(n) || n <= 0 || n > MAX_QTY) continue;
    cart[id] = Math.round(n * 1000) / 1000;
  }
  return cart;
}

export function serializeCart(cart: Cart): string {
  return JSON.stringify(cart);
}

/** qty <= 0 removes the line. Throws CART_FULL / BAD_QTY (caller maps to messages). */
export function setQty(cart: Cart, productId: string, qty: number): Cart {
  const next: Cart = { ...cart };
  if (qty <= 0) {
    delete next[productId];
    return next;
  }
  if (!Number.isFinite(qty) || qty > MAX_QTY) throw new Error("BAD_QTY");
  if (!(productId in next) && Object.keys(next).length >= CART_MAX_LINES) throw new Error("CART_FULL");
  next[productId] = Math.round(qty * 1000) / 1000;
  return next;
}
```
